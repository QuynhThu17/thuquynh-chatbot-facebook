# Changelog - 2025-10-08-006

## ✨ Feature: API GET `/api/v1/packages` - Authentication & Smart Filtering

### 🔐 Thay đổi:
1. **Thêm Authentication (Required)**
   - API yêu cầu JWT token để xác thực user
   - Sử dụng `Depends(get_current_user)` để lấy thông tin user từ token

2. **Smart Filtering cho Custom Package Users**
   - **User thường**: Trả về tất cả packages `type="default"`
   - **User có custom package**: 
     - Trả về packages `type="default"` (KHÔNG bao gồm `p_enterprise`)
     - Thêm custom package của user vào kết quả
     - Hệ số limit = `-1` (unlimited) cho custom package

### 📊 Logic chi tiết:

#### User thường:
```
Filter: type="default"
→ Hiển thị: p_free_trial, p_pro, p_business, p_enterprise
```

#### User đăng ký gói custom:
```
Filter: type="default" (trừ p_enterprise) + custom package
→ Hiển thị: p_free_trial, p_pro, p_business, <custom_package>
→ Custom package limits = -1 (unlimited) => trên giao diện để hiển thị {used}/unlimited
```

### 🔄 Breaking Changes:
- API `/api/v1/packages` **bắt buộc authentication** (trước đây không cần)
- Frontend cần truyền JWT token trong header `Authorization: Bearer <token>`

### 📝 Impact:
- Packages được filter theo đúng quyền của user
- Custom package users không thấy `p_enterprise` (tránh nhầm lẫn)
- Hệ số `-1` = unlimited cho custom packages

## 🔒 Feature: Super Admin API - User & System Management

Nếu là role super_admin hoặc white_label_admin thì cho phép vào trang admin. 
Mục đích: hiển thị, quản lý các user, packages,...

### 📦 Các API mới:

#### 1. **User Management** (`/super-admin/users`)
- `GET /super-admin/users` - Danh sách users (pagination, search, role filter)
- `GET /super-admin/users/{user_id}` - Chi tiết user với thống kê
- `POST /super-admin/users` - Tạo user mới (với package & subscription)
- `PATCH /super-admin/users/{user_id}` - Cập nhật user (extend subscription)
- `DELETE /super-admin/users/{user_id}` - Xóa user (soft delete)

**Phân quyền:**
- Super Admin: Full access toàn hệ thống
- White Label Admin: Chỉ trong hierarchy của họ

**Tính năng nổi bật:**
- Tạo user kèm package & subscription ngay lập tức
- Gia hạn subscription (extend_subscription_months)
- Tự động khởi tạo limits từ package
- Thêm user vào target_users của custom package

#### 2. **White Label Management** (`/super-admin/white-labels`)
- `GET /super-admin/white-labels` - Danh sách White Label partners
- `GET /super-admin/white-labels/{partner_id}` - Chi tiết partner
- `POST /super-admin/white-labels` - Tạo White Label partner mới
- `PATCH /super-admin/white-labels/{partner_id}` - Cập nhật partner
- `DELETE /super-admin/white-labels/{partner_id}` - Xóa partner

**Phân quyền:** Chỉ Super Admin

**Tính năng:**
- Tạo partner với API key tự động
- Quản lý license & hierarchy
- Thống kê chi tiết từng partner

#### 3. **Package Management** (`/super-admin/packages`)
- `GET /super-admin/packages` - Danh sách packages (filter theo user)
- `POST /super-admin/packages` - Tạo package (global hoặc custom)
- `PATCH /super-admin/packages/{package_id}` - Cập nhật package
- `DELETE /super-admin/packages/{package_id}` - Xóa package

**Phân quyền:**
- Super Admin: Tạo global packages
- White Label Admin: Tạo packages cho hierarchy của họ

**Tính năng:**
- Custom package với target_users
- Smart filtering theo hierarchy
- Validation không xóa package có active subscriptions

#### 4. **Subscription Management** (`/super-admin/subscriptions`)
- `GET /super-admin/subscriptions` - Danh sách subscriptions
- `GET /super-admin/subscriptions/{subscription_id}` - Chi tiết
- `POST /super-admin/subscriptions` - Tạo subscription cho user
- `PATCH /super-admin/subscriptions/{subscription_id}` - Cập nhật (gia hạn, status)
- `DELETE /super-admin/subscriptions/{subscription_id}` - Hủy subscription

**Phân quyền:**
- Super Admin: Full access
- White Label Admin: Trong hierarchy

**Tính năng:**
- Tạo subscription trực tiếp (không qua thanh toán)
- Gia hạn subscription
- Quản lý status (active, expired, cancelled)


#### 5. **Token** 
- Sắp phát triển (quản lý số lượng token)

#### 6. **Statistics & Analytics** (`/super-admin/statistics`)
- `GET /super-admin/statistics/overview` - Tổng quan hệ thống
- `GET /super-admin/statistics/white-labels/{partner_id}` - Thống kê partner
- `GET /super-admin/statistics/users/{user_id}` - Thống kê user cụ thể

**Phân quyền:**
- Super Admin: Toàn hệ thống
- White Label Admin: Hệ thống của họ (full stats)

**Metrics:**
- Users, subscriptions, revenue
- Bots, social accounts, messages
- Hierarchy stats, performance metrics

### 🔐 Bảo mật:
- JWT Authentication required
- Role-based access control (RBAC)
- Hierarchy-based permissions

### 📊 Business Logic:
- **Hierarchy-based filtering**: White Label chỉ thấy users/data trong tree của họ
- **Custom package targeting**: Package chỉ hiển thị cho users trong target_users
- **Soft delete**: Dữ liệu không bị xóa vật lý (audit trail)
- **Automatic initialization**: Tạo user tự động khởi tạo defaults (background task)

### 🎯 Use Cases:
- MekongAI quản lý toàn bộ hệ thống
- White Label quản lý hệ thống của họ (như Super Admin)
- Tạo custom packages cho khách hàng VIP
- Thống kê & analytics chi tiết
- Business intelligence & reporting
