# Changelog - 2025/10/08 #008

## Thêm API lấy thông tin package theo ID

### Endpoint mới
- **GET** `/super-admin/packages/{package_id}` - Lấy thông tin chi tiết của một package theo ID

### Chi tiết
- Trả về đầy đủ thông tin của package bao gồm: name, price, description, features, limits, duration_months, type, created_by, owner_type, target_users
- Phân quyền:
  - Super Admin: Xem tất cả packages
  - White Label Admin: Chỉ xem packages global, do họ tạo, hoặc trong hierarchy của họ
- Response codes:
  - 200: Success
  - 404: Package không tồn tại
  - 403: Không có quyền truy cập package

### Impact
- API này bổ sung cho các API packages hiện có (GET /packages, POST /packages, PATCH /packages/{id}, DELETE /packages/{id})
