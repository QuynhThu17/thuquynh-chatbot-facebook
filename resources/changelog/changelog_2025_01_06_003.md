# Changelog - 2025-01-06-003 (UPDATED)

## 🤖 LLM-Powered Query Processing với History Context

### Vấn đề
1. **Search kém hiệu quả:**
   - Bot search "có bán túi maggie không" → tìm với query nguyên văn → không tìm thấy
   - Query chứa nhiều noise words (có, không, bán, shop, em, ạ...)

2. **Mất context khi hỏi tiếp:**
   - User: "Có túi Maggie không?" → Bot: "Có ạ..."
   - User: "Bao nhiêu tiền?" → Bot không hiểu "bao nhiêu tiền" là hỏi giá túi Maggie
   - User: "Tìm nó" → Bot không biết "nó" là túi Maggie
   - **Root cause:** Agent cũ dùng LangChain ReAct có history, agent mới không có

3. **Keyword extraction thủ công kém linh hoạt:**
   - Regex patterns cứng nhắc
   - Không hiểu context câu hỏi

### Giải pháp: LLM-Powered Query Processing

#### 1. QueryRouter.process_query() - All-in-One LLM Processing
**Thay vì keyword extraction thủ công → Dùng LLM làm TẤT CẢ:**

```python
# ❌ CŨ: Keyword extraction thủ công với regex
KeywordExtractor.extract_product_keywords(query)
KeywordExtractor.extract_knowledge_keywords(query)

# ✅ MỚI: LLM xử lý toàn bộ với history context
processing_result = await router.process_query(query, history_text)
```

**LLM thực hiện 3 nhiệm vụ cùng lúc:**
1. **Intent Classification** - Phân loại: product_search, knowledge_query, order...
2. **Query Rewriting** - Viết lại query dựa trên history:
   - "bao nhiêu tiền" + history "túi Maggie" → "túi Maggie giá bao nhiêu"
   - "tìm nó" + history "túi Maggie" → "tìm túi Maggie"
3. **Keyword Extraction** - Extract keywords thông minh:
   - Tách SKU/product codes
   - Remove stop words
   - Identify brand names

**Example Output:**
```json
{
    "intent": "product_search",
    "rewritten_query": "túi Maggie giá bao nhiêu",
    "product_keywords": {
        "search_query": "túi Maggie",
        "search_query_keyword": "Maggie",
        "sku": null
    },
    "knowledge_keywords": {
        "query": "túi Maggie giá",
        "original_query": "bao nhiêu tiền"
    }
}
```

#### 2. Fast Path Optimization
**Không phải query nào cũng cần LLM:**

```python
# ✅ Fast path: Queries đơn giản không mơ hồ
if 'giá' in query and not has_ambiguity:
    return {intent: "product_search", ...}  # 0.001s

# ✅ LLM path: Queries mơ hồ hoặc cần context
if 'nó' in query or 'bao nhiêu' in query:
    result = await llm.ainvoke(...)  # 0.5s nhưng accurate
```

**Ambiguous words trigger LLM:**
- "nó", "cái này", "cái đó" → cần thay thế bằng entity cụ thể
- "bao nhiêu", "như thế nào", "thế" → cần context từ history

#### 3. History Context Integration
**Prompt Template:**
```python
HISTORY (3 câu gần nhất):
User: Có túi Maggie không?
Bot: Dạ có ạ, túi Maggie đang có sẵn...

USER QUERY: bao nhiêu tiền

→ LLM Output: "rewritten_query": "túi Maggie giá bao nhiêu"
```

#### 4. State Management
**route_query() node lưu processing result vào state.metadata:**
```python
state["metadata"] = {
    "rewritten_query": "túi Maggie giá bao nhiêu",
    "product_keywords": {...},
    "knowledge_keywords": {...}
}
```

**call_tools_parallel() node lấy từ metadata:**
```python
metadata = state.get("metadata", {})
product_keywords = metadata.get("product_keywords")

# Pass to tools
search_products(
    search_query=product_keywords['search_query'],  # "túi Maggie"
    search_query_keyword=product_keywords['search_query_keyword']  # "Maggie"
)
```
