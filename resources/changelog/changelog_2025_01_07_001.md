# Changelog 2025-01-07-001

## 🐛 Fix: Image Search Issues - Query Limitation + LLM Misinterpretation

### Vấn đề:
1. Image search luôn chỉ match với 1 loại sản phẩm (ví Jestina), không tìm thấy sản phẩm khác
2. **ROOT CAUSE #1:** Query chỉ lấy 50 chunks đầu tiên (limit=limit*10), miss hầu hết products trong DB
3. **ROOT CAUSE #2:** LLM không tin tưởng kết quả tool, tự ý nói "chưa có sản phẩm" dù tool đã tìm thấy match 100%
4. Vectors không được normalize đúng cách
5. Thiếu logging chi tiết để debug flow và troubleshoot

### Nguyên nhân chi tiết:
- **Issue #1:** Database có hàng trăm sản phẩm với image chunks
  - Nhưng `get_all(limit=50)` chỉ lấy 50 chunks đầu tiên (sorted by _id)
  - Nếu 50 chunks đầu tiên đều là Jestina → chỉ match Jestina!
  - Các sản phẩm khác (túi bucket, túi xách, ví,...) bị bỏ qua hoàn toàn
  
- **Issue #2:** LLM không hiểu tool response khi similarity = 100%
  - Tool tìm thấy: "Ví ngắn màu xanh cobalt Lee - 100% match"
  - LLM trả lời: "Dạ, KAT hiện chưa có đúng mẫu túi như hình anh gửi"
  - Nguyên nhân: Tool response không rõ ràng, LLM không tin tưởng kết quả

### Thay đổi:

#### 1. **🔥 CRITICAL FIX: Query ALL Chunks (Unlimited)**
- **Trước:** `get_all(limit=limit * 10)` → chỉ 50 chunks
- **Sau:** `get_all(limit=0)` → lấy HẾT tất cả chunks (unlimited)
- **Lý do:** 
  - 50 chunks không đủ để cover toàn bộ products trong DB
  - Chunks được sort theo `_id` (thứ tự upload), không phải similarity
  - Nếu product A upload trước → chiếm hết 50 slots → products khác bị miss
  - Database lớn có thể có >1000 chunks → cần unlimited
- **Impact:** 🚀 Tăng coverage từ ~10 products lên 100% (toàn bộ DB)

#### 2. **Enhanced BaseManager to Support Unlimited Query**
- **File:** `base_manager.py` - Function `get_all()`
- **Fix:** Support `limit=0` hoặc `limit=None` để query không giới hạn
- **Before:** 
  ```python
  cursor = cursor.limit(limit)
  docs = await cursor.to_list(length=limit)
  ```
- **After:**
  ```python
  if limit and limit > 0:
      cursor = cursor.limit(limit)
      docs = await cursor.to_list(length=limit)
  else:
      docs = await cursor.to_list(length=None)  # Unlimited
  ```

#### 3. **Fix Text Search Limit**
- **Function:** `search_products_by_text()`
- **Trước:** `limit=50` (default)
- **Sau:** `limit=100` (default)
- **Thêm logging:** Log query, filter, và kết quả count

#### 4. **🔥 CRITICAL: Enhanced Tool Response for Exact Match**
- **Problem:** LLM không tin tưởng kết quả 100% match
- **Solution:** Phân biệt rõ ràng EXACT match vs Similar products
- **Before:**
  ```
  🖼️ TÌM THẤY 5 SẢN PHẨM TƯƠNG TỰ:
  1. 📦 Ví ngắn màu xanh cobalt Lee
     - Độ tương đồng: 100.0%
  ```
- **After:**
  ```
  ✅ TÌM THẤY SẢN PHẨM CHÍNH XÁC TRONG ẢNH!
  Đây chính xác là sản phẩm trong ảnh anh gửi:
  
  1. ✅ **Ví ngắn màu xanh cobalt Lee** (CHÍNH XÁC - 100% giống)
     - Mã: LEE001
     - Giá: 790,000 VNĐ
  
  ✅ QUAN TRỌNG: Sản phẩm đầu tiên là KẾT QUẢ CHÍNH XÁC 100%
     Hãy sử dụng thông tin này để trả lời khách hàng.
  ```
- **Impact:** LLM sẽ hiểu rõ và trả lời đúng sản phẩm

#### 5. **Giảm Similarity Threshold**
- **Trước:** `SIMILARITY_THRESHOLD = 0.7` (70%)
- **Sau:** `SIMILARITY_THRESHOLD = 0.5` (50%)
- **Lý do:** Image similarity thường thấp hơn text similarity, ảnh cùng loại sản phẩm có thể chỉ đạt 50-70%

### Optimization Notes:

  1. Thêm index cho `chunk_type` + `company_id`
  2. Dùng vector database (Qdrant, Pinecone) thay vì MongoDB
  3. Cache similarity scores
  4. Batch processing để tránh timeout
