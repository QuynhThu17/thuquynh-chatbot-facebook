# Changelog - 2025/11/07 #001

## Cải thiện Message Buffer Logic - Gộp tin nhắn liên tiếp thông minh

### Vấn đề:
- Khách hàng thường gửi nhiều tin nhắn ngắn liên tiếp: "hi", "có sp này không", "giá bao nhiêu"
- Bot xử lý từng tin riêng lẻ → chậm và lãng phí token
- Logic buffer cũ chỉ dựa vào `buffer_time` cố định → không tối ưu

### Thay đổi:
**File: `bot/bot_facebook_messenger.py`**

1. **Thêm tracking state cho buffer:**
   - `is_processing`: Đang xử lý tin nhắn
   - `response_sent`: Đã gửi response về Messenger

2. **Logic buffer thông minh:**
   - ✅ Nếu bot **chưa gửi response** (`response_sent = False`):
     - Cancel task cũ ngay lập tức
     - Gộp tin nhắn mới vào buffer
     - Reset timer
   
   - ✅ Nếu bot **đã gửi response** (`response_sent = True`):
     - Tạo buffer mới cho tin nhắn này
     - Không gộp với buffer cũ

3. **Auto cleanup:**
   - Buffer tự động xóa sau 5 giây kể từ khi gửi response
   - Tránh memory leak

### Kết quả:
- ✅ Gộp được tất cả tin nhắn liên tiếp **trước khi bot phản hồi**
- ✅ Không gộp nhầm tin nhắn **sau khi bot đã trả lời**
- ✅ Tiết kiệm token LLM
- ✅ Trải nghiệm người dùng tốt hơn

### Ví dụ:
```
User: "hi" (0s)
User: "có túi maggie không" (0.5s)
User: "giá bao nhiêu" (1s)

→ Bot nhận: "hi\ncó túi maggie không\ngiá bao nhiêu" (sau 2s)
→ Xử lý 1 lần thay vì 3 lần
```
