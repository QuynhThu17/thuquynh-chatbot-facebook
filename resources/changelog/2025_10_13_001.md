# Dashboard Overview API - Fix Date Range Query & Chart Context

**Date**: 2025-10-13  
**Type**: Bugfix + Enhancement  
**API**: `GET /api/v1/dashboard/overview`

## Vấn đề
1. Dashboard không lấy được dữ liệu đúng cho period `today` và các period khác
2. Query MongoDB sử dụng `$lt` (less than) thay vì `$lte` (less than or equal) dẫn đến thiếu dữ liệu trong ngày
3. Biểu đồ trống trơn khi filter theo period ngắn (today, week) - không có context để so sánh

## Thay đổi

### 1. Sửa logic date range
- Thay đổi end time từ "start of next day" sang "23:59:59.999999 of current day"
- Đổi tất cả query từ `$lt` sang `$lte` để bao gồm cả end_date
- Cải thiện timezone handling (naive datetime)

### 2. **Chart Context Enhancement** ✨
- **Today**: Chart hiển thị 7 ngày (6 ngày trước + hôm nay) thay vì chỉ 1 ngày
- **Week**: Chart hiển thị 4 tuần (3 tuần trước + tuần này) thay vì chỉ 1 tuần  
- **Month**: Chart hiển thị 3 tháng (2 tháng trước + tháng này) thay vì chỉ 1 tháng
- **Year/All**: Giữ nguyên

### 3. Fill Missing Dates
- Tự động fill các ngày/giờ thiếu với count = 0
- Đảm bảo chart luôn có đủ data points, không bị trống
- Thêm field `is_current_period` để FE có thể highlight period được chọn

### 4. Thêm logging
- Log date range khi query
- Log count result từ mỗi collection
- Giúp debug dễ dàng hơn

## Response Structure Changes

**KHÔNG có breaking changes** - chỉ thêm field mới:

## Impact
✅ Dashboard giờ hiển thị đúng dữ liệu cho period `today`  
✅ Các period khác (week, month, year) cũng chính xác hơn  
✅ **Biểu đồ luôn có context** - không còn trống trơn  
✅ FE có thể highlight period được chọn qua field `is_current_period`  
✅ Response structure backward compatible - không breaking change  

## Frontend Usage

```javascript
// FE có thể dùng is_current_period để highlight
data.forEach(point => {
  if (point.is_current_period) {
    // Highlight hoặc style khác cho period được chọn
    chart.highlight(point);
  } else {
    // Context data - hiển thị mờ hơn
    chart.addContext(point);
  }
});
```
