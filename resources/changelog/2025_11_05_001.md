# Changelog 2025-11-05 #001

## Thêm API Upload Nhiều Hình Ảnh

### Endpoints Mới

#### 1. POST `/api/v1/images/upload-images`
- Upload nhiều hình ảnh cùng lúc (tối đa 10 files)
- Xử lý song song để tối ưu thời gian
- Mỗi file tối đa 10MB
- Hỗ trợ: jpg, jpeg, png, gif, bmp, webp

**Response:**
```json
{
  "success": true,
  "message": "All images uploaded successfully",
  "total_files": 3,
  "successful_uploads": 3,
  "failed_uploads": 0,
  "results": [
    {
      "success": true,
      "filename": "image1.jpg",
      "image_url": "https://bucket.s3.amazonaws.com/...",
      "error": null
    },
    {
      "success": true,
      "filename": "image2.png",
      "image_url": "https://bucket.s3.amazonaws.com/...",
      "error": null
    }
  ]
}
```

#### 2. POST `/api/v1/images/upload-image`
- Upload một hình ảnh đơn lẻ
- File tối đa 10MB
- Hỗ trợ: jpg, jpeg, png, gif, bmp, webp

**Response:**
```json
{
  "success": true,
  "filename": "image.jpg",
  "image_url": "https://bucket.s3.amazonaws.com/...",
  "error": null
}
```

### Tính Năng
- Upload song song nhiều file để tối ưu thời gian
- Validation file type và size
- Trả về thông tin chi tiết cho từng file
- Xử lý lỗi riêng biệt cho từng file
