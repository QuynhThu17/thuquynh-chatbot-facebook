# Changelog - 2025-10-09-003

## Tối ưu hóa tốc độ xử lý tin nhắn Facebook Messenger

### Thay đổi

**Bot Facebook Messenger:**
- Chuyển `send_typing_action` (mark_seen và typing_on) sang chạy trong thread riêng để không block luồng chính
- Chuyển `send_facebook_messenger` và `save_conversation_message` sang background tasks (asyncio.create_task) để không chờ khi gửi response
- Chuyển sticker response sang background task

**API Social Media (send_facebook_message):**
- Chuyển `send_facebook_messenger` và `save_history` sang background task để response API nhanh hơn

### Lợi ích

1. **Tốc độ response nhanh hơn**: Không cần chờ Facebook API calls và database operations hoàn thành
2. **User experience tốt hơn**: Typing indicators được gửi ngay lập tức trong background
3. **Throughput cao hơn**: Xử lý được nhiều requests đồng thời hơn
4. **Non-blocking**: Các operations không quan trọng không làm chậm luồng chính

### Ảnh hưởng API

- Response time của endpoint `/api/v1/socials/send-facebook-message` sẽ nhanh hơn đáng kể
- Bot response trong Facebook Messenger sẽ xuất hiện nhanh hơn cho người dùng

### Technical Details

- Sử dụng `threading.Thread` cho sync operations (send_typing_action)
- Sử dụng `asyncio.create_task` cho async operations (send_facebook_messenger, save_history)
- Tất cả background tasks đều có error handling để không ảnh hưởng main flow
