# Changelog 2025-11-05-003

## Fix: Order Notification Parameters

### Sửa lỗi TypeError trong order notifications
- Fix `notify_order_created()` - Thêm tham số `order_code`, `order_id`, `total_price` (thay vì `customer_name`, `total_amount`)
- Fix `notify_order_status_changed()` - Thêm tham số `order_code`, cho phép `old_status` optional
- Fix `notify_order_updated()` - Thêm tham số `order_code`, cho phép `changes` optional
- Fix `notify_order_cancelled()` - Sử dụng `order_code` là tham số chính, `order_id` optional

### Thêm notification methods mới
- `notify_order_updated()` - Thông báo cập nhật đơn hàng
- `notify_order_cancelled()` - Thông báo hủy đơn hàng
- `notify_customer_deleted()` - Thông báo xóa khách hàng

### Impact
- Các order notifications giờ sử dụng `order_code` để hiển thị thay vì `order_id`
- Notification metadata bao gồm cả `order_code` và `order_id`
- Không còn lỗi TypeError khi tạo order mới
