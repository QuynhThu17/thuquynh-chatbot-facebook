# Changelog 2025-11-07-002

## � Feature: Image-Based Product Search

### Vấn đề
1. Chức năng tìm kiếm ảnh trong knowledge base không hoạt động do lỗi biến global `image_model` và `image_processor` chưa được khai báo.
2. Regex pattern để extract image URLs không nhận diện được đầy đủ các domain Facebook CDN.
3. **QUAN TRỌNG**: Khách hàng thường upload ảnh sản phẩm và hỏi về giá, màu sắc, v.v. nhưng hệ thống chưa tự động tìm sản phẩm tương tự từ ảnh.

### Tính năng mới
**🖼️ Tìm kiếm sản phẩm bằng ảnh (Image-Based Product Search)**:
- Tự động phát hiện khi user gửi ảnh vào chat
- Tải ảnh về và tạo embedding bằng SigLIP model
- So sánh với ảnh sản phẩm trong database bằng vector similarity
- Tìm sản phẩm tương tự (không cần giống 100%, chỉ cần tương tự về màu sắc, hình dáng, kiểu dáng)
- Trả về danh sách sản phẩm kèm độ tương đồng (similarity score)

### Thay đổi

#### 1. **bot/tools/facebook_messenger_tools.py**
- Thêm tool mới `search_products_by_image`:
  - Download ảnh từ URL
  - Gọi `product_enhanced_manager.search_products_by_image()` để tìm sản phẩm tương tự
  - Trả về top N sản phẩm kèm similarity score, giá, màu sắc, mô tả
  - Hỗ trợ lọc theo category, price range
- Thêm vào danh sách tools của agent

#### 2. **bot/agent_graph.py**
- Cập nhật `route_query` node:
  - Tự động detect image URLs trong message (Facebook CDN, http/https)
  - Tự động thêm `search_products_by_image` vào tools_to_call khi phát hiện ảnh
  - Lưu image URLs vào metadata để dùng cho tool calling
- Cập nhật `call_tools_parallel` node:
  - Thêm xử lý cho `search_products_by_image` tool
  - Cho phép chạy song song với `search_products` và `search_knowledge`
  - Lấy image URL từ metadata và truyền vào tool

#### 3. **bot/bot_facebook_messenger.py**
- Fix lỗi global variables:
  - Thêm `global image_model, image_processor` trong `search_image_in_knowledge()`
- Cải thiện regex patterns:
  - Mở rộng `image_url_fb` để match nhiều subdomain Facebook CDN
  - Thêm `image_url_fb_cdn` để match bất kỳ URL nào chứa "fbcdn" hoặc "fbsbx"
- Thêm logging chi tiết trong `extract_image_urls_from_message()`

### Luồng hoạt động

**Khi user upload ảnh:**
```
1. Webhook nhận message với attachment image
2. extract_message_data() → MessageData(type="image_url", content=URL)
3. process_facebook_message() → message=URL được truyền vào bot
4. route_query() → Detect image URL → Thêm search_products_by_image vào tools
5. call_tools_parallel() → Gọi search_products_by_image với URL
6. Tool tải ảnh → Tạo embedding → Vector search trong products
7. Trả về sản phẩm tương tự kèm similarity score
8. LLM nhận kết quả → Generate response tự nhiên
```

### Impact
✅ **Khách hàng có thể**:
- Gửi ảnh sản phẩm và hỏi "cái này bao nhiêu tiền?"
- Gửi ảnh và hỏi "có màu khác không?"
- Gửi ảnh tương tự và bot tự tìm sản phẩm gần giống nhất
- Nhận thông tin chi tiết về sản phẩm (giá, màu, SKU) ngay lập tức

✅ **Cải thiện trải nghiệm**:
- Không cần gõ tên sản phẩm, chỉ cần chụp/gửi ảnh
- Bot thông minh hơn, hiểu được cả hình ảnh
- Tăng tỷ lệ chuyển đổi (conversion rate) vì dễ tìm sản phẩm hơn

✅ **Kỹ thuật**:
- Sử dụng SigLIP model (state-of-the-art cho image similarity)
- Vector search nhanh với Qdrant
- Parallel execution để không ảnh hưởng tốc độ response
- Auto-detect image không cần user chỉ định
