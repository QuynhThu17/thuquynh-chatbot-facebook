# Changelog - 2025-11-05-006

## Tích hợp RAGFlow DeepDOC Parser làm mặc định

### 🎯 Thay đổi lớn

**Tích hợp RAGFlow Document Parser** - Engine parsing document mạnh mẽ với khả năng hiểu layout và cấu trúc tốt hơn.

### API Changes

#### POST `/api/v1/knowledge/documents/upload`
- **Thêm param mới**: `parser_engine` (string, mặc định: `"ragflow"`)
  - `"ragflow"`: Sử dụng RAGFlow DeepDOC parser (mặc định - tốt nhất)
  - `"legacy"`: Sử dụng parser cũ (fallback)

### Chi tiết thay đổi

**1. RAGFlow Parser Integration**
- Tích hợp RAGFlow's DeepDOC parser làm engine mặc định
- Hỗ trợ advanced layout recognition
- Better table extraction
- Preserve document structure

**2. Parser Features**
- **PDF**: Layout-aware parsing với pdfplumber
- **DOCX**: Structure preservation with style detection
- **Excel**: Multi-sheet support with table formatting
- **Auto-fallback**: Tự động fallback về legacy parser nếu RAGFlow fail

**3. Backward Compatibility**
- Giữ nguyên legacy parsers
- API params tương thích ngược
- User có thể chọn parser engine
- Default là RAGFlow (tốt nhất)

**4. Performance & Quality**
- Better text extraction quality
- Improved table detection
- Layout structure preservation
- Smart content grouping

### Architecture

```
User Request
    ↓
API Endpoint (parser_engine="ragflow")
    ↓
RAGAPIService
    ↓
DocumentLoaderService
    ↓
RAGFlowParser (mặc định) ← → Legacy Processors (fallback)
    ↓
Document Content → Chunking → Embedding → Storage
```

### Ví dụ sử dụng

```javascript
// Upload với RAGFlow (mặc định - tốt nhất)
const formData = new FormData();
formData.append('file', file);
formData.append('name', 'Document name');
formData.append('parser_engine', 'ragflow'); // Mặc định

// Upload với legacy parser (nếu cần)
formData.append('parser_engine', 'legacy');
```
