# Changelog 2025-11-06-003

## Fix: Bot trả về JSON thay vì câu trả lời tự nhiên

### Vấn đề
- Bot trả về JSON format `{"tool":"search_knowledge",...}` thay vì câu trả lời tự nhiên
- Nguyên nhân: 
  1. Prompt có phần Tools instruction khiến LLM nghĩ phải format output dạng JSON để gọi tool
  2. Thực tế việc gọi tool đã do `QueryRouter` và `ToolSelector` quyết định, không phải LLM
  3. LLM trong `generate_response()` chỉ cần tạo response từ tool results, không cần gọi tool

### Kiến trúc hiện tại
**Flow xử lý query:**
```
1. route_query() 
   → QueryRouter.process_query() (LLM classify intent + extract keywords)
   → ToolSelector.select_tools() (chọn tools dựa vào intent)

2. call_tools_parallel()
   → Gọi các tools đã được chọn

3. generate_response()
   → LLM tạo response từ tool results
   → ❌ VẤN ĐỀ: Prompt vẫn có phần Tools khiến LLM nghĩ phải gọi tool
```

### Thay đổi

**1. Tạo prompt mới cho response generation (File: `configs/prompts/prompt_facebook_messenger.py`):**
- Thêm `FACEBOOK_MESSENGER_RESPONSE_ONLY` - prompt không có phần Tools
- Thay `Scratchpad` instruction để rõ ràng đây là kết quả từ tools đã gọi
- Thêm nhiều cảnh báo: "DO NOT output JSON", "Output must be NATURAL LANGUAGE TEXT ONLY"
- Bổ sung example về format output đúng

**2. Cập nhật `agent_graph.py`:**
- `generate_response()` dùng `FACEBOOK_MESSENGER_RESPONSE_ONLY` thay vì `FACEBOOK_MESSENGER`
- LLM chỉ nhận tool results qua `agent_scratchpad`, không nhận Tools instruction

**3. Giữ nguyên prompt gốc `FACEBOOK_MESSENGER`:**
- Có thể dùng cho future features (nếu cần LLM tự quyết định gọi tool)
- Backward compatibility
