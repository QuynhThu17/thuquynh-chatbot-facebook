# Changelog 2025-11-05-002

## API: POST /api/v1/crm/orders

### Thay đổi
- Sửa lỗi API `POST /api/v1/crm/orders` không tạo được order do parameter mismatch
- Điều chỉnh logic tạo order để phù hợp với signature của `OrderManager.create_order()`

### Chi tiết
- Tự động tạo mã order với format `ORD-XXXXXXXX` (8 ký tự hex uppercase)
- Map `customer_id` từ request sang `contact_id` trong OrderManager
- Chuyển đổi thông tin sản phẩm đơn lẻ thành `line_items` array
- Bổ sung các thông tin social media và customer vào order sau khi tạo

### Các tham số request vẫn giữ nguyên
- `social_id`, `social_page_id`, `customer_id`, `product_name`, `unit_price`, `quantity`, `total_price`
- `customer_note`, `customer_name`, `customer_phone`, `customer_address`
- `payment_method`, `payment_status`, `status`
