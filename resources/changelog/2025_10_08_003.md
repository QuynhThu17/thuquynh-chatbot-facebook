# Changelog 2025-10-08-003

## 🐛 Bug Fix: Package target_users không được lưu vào database

### Vấn đề
- Log hiển thị "✅ Added user to custom package target_users" nhưng database không được update
- Code đang dùng filter `{"package_id": request.package_id}` để update nhưng packages collection dùng `_id` làm primary key

### Nguyên nhân
- `PackageManager` kế thừa từ `BaseManager`, method `get_by_id()` tìm theo trường `_id`
- Nhưng code update lại dùng filter `{"package_id": ...}` thay vì `{"_id": ...}`
- Dẫn đến MongoDB không tìm thấy document để update

### Giải pháp
- Sửa tất cả các đoạn update target_users từ:
  ```python
  await factory.package_manager.collection.update_one(
      {"package_id": request.package_id},  # ❌ SAI
      {"$set": {...}}
  )
  ```
  
  Thành:
  ```python
  package_object_id = package.get("_id")
  await factory.package_manager.collection.update_one(
      {"_id": package_object_id},  # ✅ ĐÚNG
      {"$set": {...}}
  )
  ```
