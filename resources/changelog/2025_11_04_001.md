# Changelog - 2025-11-04-001

## Thêm trường mặc định cho Customers và API quản lý Auto Reply

### Thay đổi trong Database (customers collection)
- Thêm 3 trường mới cho customers:
  - `auto_reply` (bool): Trạng thái tự động trả lời, mặc định `true`
  - `status` (string): Trạng thái khách hàng, mặc định `"Tương tác"`
  - `tags` (array): Danh sách tags, mặc định `[]`

### API mới

#### 1. Toggle Auto Reply (Đơn lẻ)
**PATCH** `/api/v1/crm/customers/{customer_id}/auto-reply`
- Tự động toggle trạng thái auto_reply (True ↔ False)
- Không cần body, chỉ cần gọi API
- Response: trạng thái mới, tên customer, message

**Cách dùng Frontend:**
```javascript
// Đơn giản chỉ cần gọi PATCH
await fetch(`/api/v1/crm/customers/${customerId}/auto-reply`, {
  method: 'PATCH',
  headers: { 'Authorization': `Bearer ${token}` }
})
```

#### 2. Batch Toggle Auto Reply (Nhiều customers)
**POST** `/api/v1/crm/customers/batch/auto-reply`
- Body: `{ "customer_ids": ["id1", "id2"], "enable": true/false/null }`
- `enable=true`: Bật tất cả
- `enable=false`: Tắt tất cả  
- `enable=null` hoặc không truyền: Toggle từng customer
- Response: số lượng thành công/thất bại, chi tiết từng customer

**Cách dùng Frontend:**
```javascript
// Bật cho nhiều customers
await fetch('/api/v1/crm/customers/batch/auto-reply', {
  method: 'POST',
  headers: { 
    'Authorization': `Bearer ${token}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    customer_ids: ['id1', 'id2', 'id3'],
    enable: true  // hoặc false, hoặc không truyền để toggle
  })
})
```

### API được cập nhật
- **GET /api/v1/crm/customers**: Tự động trả về `auto_reply`, `status`, `tags` trong danh sách
- **POST /api/v1/crm/customers**: Tự động thêm 3 trường mặc định khi tạo mới
- **PUT /api/v1/crm/customers/{customer_id}**: Có thể cập nhật `auto_reply`, `status`, `tags`
