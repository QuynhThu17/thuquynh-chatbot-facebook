# Changelog 2025-10-08 #007

## API mới: Gửi tin nhắn tới Facebook Messenger

### Endpoint
- **POST** `/api/v1/socials/facebook/send-message`

### Tính năng
- Gửi tin nhắn (text/image/images) tới Facebook Messenger
- Xác thực người dùng phải sở hữu page trước khi gửi
- Lưu đầy đủ lịch sử tin nhắn vào database

### Request Body
```json
{
  "page_id": "string",
  "sender_id": "string",
  "messages": [
    {
      "type": "text|image|images",
      "data": "string hoặc array"
    }
  ]
}
```

### Response
```json
{
  "success": true,
  "message": "Message sent successfully",
  "data": {
    "page_id": "...",
    "sender_id": "...",
    "message_count": 1
  }
}
```

### Validation
- Kiểm tra page_id có thuộc về user không
- Validate format của messages
- Lưu lịch sử tin nhắn với đầy đủ thông tin

### Files changed
- `api/v1/socials/api_social_media.py`: Thêm endpoint mới và model `SendMessageRequest`
