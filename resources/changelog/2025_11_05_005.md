# Changelog - 2025-11-05-005

## Thêm tính năng xử lý ảnh có thể bật/tắt cho upload tài liệu

### API Changes

#### POST `/api/v1/knowledge/documents/upload`
- **Thêm param mới**: `process_images` (boolean, mặc định: `false`)
  - `true`: Xử lý ảnh trong tài liệu (chậm hơn)
  - `false`: Bỏ qua ảnh trong tài liệu (nhanh hơn, mặc định)

### Chi tiết thay đổi

**1. Image Processing Control**
- Thêm flag `process_images` để cho phép người dùng chọn có xử lý ảnh hay không
- Mặc định `false` để tối ưu tốc độ xử lý tài liệu
- Khi `true`, hệ thống sẽ extract và upload ảnh lên S3

**2. Image Deduplication**
- Khi `process_images=true`, hệ thống tự động phát hiện và loại bỏ ảnh trùng lặp
- Sử dụng MD5 hash để detect ảnh trùng (logo, watermark, etc.)
- Tái sử dụng URL của ảnh đã upload cho các ảnh trùng lặp
- Giảm thiểu số lần upload lên S3 và tiết kiệm storage

**3. Performance Improvement**
- Khi `process_images=false`: Xử lý nhanh hơn 2-3 lần (chỉ extract text)
- Khi `process_images=true`: Tối ưu bằng deduplication, giảm upload time

### Ví dụ sử dụng

```javascript
// Upload nhanh (không xử lý ảnh)
const formData = new FormData();
formData.append('file', file);
formData.append('name', 'Document name');
formData.append('process_images', false); // Mặc định

// Upload với xử lý ảnh
formData.append('process_images', true);
```
