### **Part 3: Fix ObjectId Error** ⚠️ **HOTFIX**

#### Vấn Đề:
❌ **Error 1**: `'p_mekongai' is not a valid ObjectId`
❌ **Error 2**: `'PackageManager' object has no attribute 'update_one'`

#### Nguyên Nhân:
1. Package trong hệ thống có 2 fields:
   - `_id`: ObjectId MongoDB (auto-generated)
   - `package_id`: String custom (vd: `"p_mekongai"`, `"p_free_trial"`)
   - Code đang dùng sai field: `update_by_id(package_id)` → expect ObjectId, nhận string

2. `BaseManager` không có method `update_one()`, chỉ có `update_by_id()`

#### Giải Pháp:
✅ **Sử dụng trực tiếp `collection.update_one()` của PyMongo**

**Trước (Lỗi 1):**
```python
await factory.package_manager.update_by_id(request.package_id, {
    "target_users": target_users,
    "type": "custom"
})
# ❌ Lỗi: request.package_id = "p_mekongai" (string) không phải ObjectId
```

**Trước (Lỗi 2):**
```python
await factory.package_manager.update_one(
    filter_query={"package_id": request.package_id},
    update_data={"target_users": target_users, "type": "custom"}
)
# ❌ Lỗi: PackageManager không có method update_one()
```

**Sau (Fixed):**
```python
# ✅ Dùng collection.update_one() trực tiếp
await factory.package_manager.collection.update_one(
    {"package_id": request.package_id},  # Filter by string field
    {"$set": {
        "target_users": target_users,
        "type": "custom",
        "update_at": get_vietnam_now_naive()
    }}
)
# ✅ OK: Dùng PyMongo native method, không cần ObjectId
```

### **Part 4: Refine Custom Package Detection Logic** ⭐ NEW

#### Vấn Đề:
- ❌ Package như `p_mekongai` có `type="default"` và `target_users=[]` KHÔNG được detect là custom
- ❌ Logic cũ: `if package_type == "custom" OR target_users có entries` → Requires EITHER condition
- ❌ Packages mới với `type="default"` và `target_users=[]` không match điều kiện
- ❌ `target_users` không được populate → GET /api/v1/packages không filter được

#### Nguyên Nhân:
```python
# Logic CŨ (SAI):
if package_type == "custom" or (target_users and len(target_users) > 0):
    # Chỉ chạy nếu package đã có type="custom" HOẶC đã có target_users entries
```

- Logic này yêu cầu package ĐÃ được đánh dấu "custom" trước đó
- Hoặc package phải ĐÃ CÓ users trong `target_users` array
- Packages mới không thỏa bất kỳ điều kiện nào → Không được track
