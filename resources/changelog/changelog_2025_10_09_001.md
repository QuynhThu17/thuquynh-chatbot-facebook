# Changelog 2025-10-09-001

## API Knowledge Management - Q&A Backup

### Thay đổi
- **POST /api/v1/knowledge/qa-pairs**: Khi tạo Q&A pair thành công, hệ thống sẽ tự động backup dữ liệu vào file `resources/backup/kat_qa.json`

### Chi tiết
- Mỗi Q&A pair được tạo sẽ được lưu vào đầu danh sách trong file backup
- File backup chứa các thông tin: qa_id, chunk_id, question, content, category, tags, company_id, user_id, created_at
- Backup không ảnh hưởng đến kết quả trả về của API nếu có lỗi xảy ra trong quá trình backup

### Bug Fix
- Xử lý trường hợp file JSON rỗng hoặc không đúng định dạng
- Tự động tạo mới file nếu bị lỗi JSON
