# Changelog - 2025-11-06-002

## Bot Test API - Thêm Company ID Support

### Thay đổi
- Thêm tham số `company_id` (optional) vào các API test bot:
  - `POST /test-bot`
  - `POST /test-bot/buffered`
  - `POST /test-bot/batch`

### Chi tiết
- Nếu `company_id` không được cung cấp, hệ thống sẽ tự động lấy company mặc định của user (owner của bot) thông qua `get_default_company_by_user_id()`
- `company_id` được truyền xuyên suốt qua các layer:
  - API → `process_facebook_message` 
  - → `process_message_immediate` / `process_message_buffered`
  - → MessageBuffer → `_process_and_send_response`
- Hỗ trợ cả xử lý immediate và buffered message
- `company_id` được ưu tiên sử dụng trong:
  - QA pairs search: `search_qa_pairs(query, company_id=effective_company_id)`
  - Conversation history: `save_conversation_message(..., company_id=company_identifier)`
  - LLM token logging: `log_llm_token_usage(..., company_id=company_identifier)`

### Logic lấy company_id
```python
# Trong process_facebook_message
if not company_id:
    # Lấy bot info → user_id → default company
    bot_info = await get_bot_info_from_bot_id(bot_id) or await get_bot_info_from_page_id(page_id)
    if bot_info and bot_info.get('user_id'):
        default_company = await factory.crm_factory.company_manager.get_default_company_by_user_id(user_id)
        if default_company:
            company_id = str(default_company.get('_id'))
```

### Ảnh hưởng
- Response của các API test bot giữ nguyên format
- Các tools trong bot agent có thể sử dụng `company_id` để lọc dữ liệu theo company
- QA pairs và conversation history được gắn với đúng company
- Token usage được track theo đúng company
